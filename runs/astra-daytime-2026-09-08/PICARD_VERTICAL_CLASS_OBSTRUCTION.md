# Vertical divisors obstruct Q-factoriality of every DVR smoothing model

**PROVED (new derivation, pending independent human review).** Let
f:Y→Spec C[[q]] be any projective flat smoothing with special fibre X_M,
geometrically connected smooth generic fibre, and the given polarization H.
Then Y is normal, Pic(Y)=Z·H, but Y cannot be Q-factorial. The same conclusion
holds after every finite ramified base change with residue field C.

The special fibre is Cohen–Macaulay and reduced. Flatness lifts
Cohen–Macaulayness to Y. The generic fibre is smooth; the generic points of
the special components are smooth points of the morphism. Thus Y satisfies
S2 and R1 and is normal. Its generic fibre is integral, and flatness excludes
additional vertical irreducible components of Y, so Y is integral.

The conceptual computation Pic(X_M)=Z·H is given in PICARD_HODGE_PLAN.md.
The obstruction sequence for each q-adic thickening, with H1(O_X_M)=
H2(O_X_M)=0, identifies all their Picard groups. Grothendieck existence for
the projective scheme over the complete DVR therefore gives Pic(Y)=Z·H.

Write the reduced special fibre as D1+...+D20. Suppose mD1 were Cartier for
some positive integer m. Its line bundle is O_Y(nH). On the generic fibre
it is trivial, and H has degree20, so n=0. Therefore mD1 is a principal
Weil divisor div(g). The rational function g restricts to a rational
function with no zeros or poles on the smooth proper integral generic
fibre. Normality makes it an invertible global regular function there.
Geometric connectedness and properness give g∈C((q))*.
But then div(g)=ord_q(g)(D1+...+D20), contradicting div(g)=mD1.

More precisely, closure of generic divisors gives an exact sequence

0 → Z·(1,...,1) → Z^20 → Cl(Y) → Pic(Y_eta) → 0.

The first arrow accounts for div(q), and the same constant-function
argument identifies the entire kernel of the vertical-divisor map.
Consequently Cl(Y) contains a rank19 vertical subgroup; this subgroup has
zero intersection with Pic(Y)=Z·H. A Q-factorial model would make every
vertical class rationally Cartier, which is impossible.

**FAILED** route: prove all completed local class groups vanish or are
torsion, then infer rho=1. The necessary global Q-factorial conclusion
contradicts the argument above.

**OPEN** replacement: prove Cl(Y)_Q is generated by H and the twenty
vertical components, after a finite extension over which the geometric
Neron–Severi classes descend. This would give rho=1. Local class-group
computations must track the images of the incident vertical components
and their global compatibility; vanishing of the local class groups is
the wrong target.

This derivation strengthens and supersedes the merely conditional
Q-factorial route recorded in PICARD_HODGE_DISCOVERY.md, item5.
